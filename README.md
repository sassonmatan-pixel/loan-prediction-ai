# חיזוי הלוואות (Loan Prediction)

מערכת לחיזוי אישור הלוואות מבוססת למידת מכונה, עם שרת FastAPI וממשק משתמש בעברית (RTL) הכולל טופס חיזוי ולוח בקרה לניתוח ביצועי המודל.

הפרויקט מבוסס על [`Loan_Forecasting_Project.ipynb`](Loan_Forecasting_Project.ipynb) — המחברת (notebook) שבה פותח ואומן ה-pipeline המקורי (עיבוד נתונים, `StandardScaler` + `SVC` עם קרנל RBF, וחיפוש היפרפרמטר `C`). קוד השרת ב-`app.py` משכפל את אותה שיטת אימון בדיוק, כדי שהתוצאות יהיו עקביות בין המחברת לאפליקציה החיה.

## תכונות

- טופס חיזוי הלוואה בעברית (RTL) עם ולידציה, וממשק דו-לשוני (עברית/אנגלית).
- לוח בקרה "מקרא המודל" — פיצ'רים, דיוק, וגורמי החיזוי.
- לוח "ניתוח ביצועים" — מטריצת בלבול, דוח סיווג, גבול החלטה דו-ממדי (PCA על פונקציית ההחלטה האמיתית של המודל), התפלגות שולי החלטה, ודגימות דאטה גולמיות — הכל מחושב בזמן אמת מהמודל השמור.
- טיפול יזום במצב שבו קובץ המודל חסר: באנר התראה וניטרול כפתור החיזוי, במקום שגיאת שרת.

## מבנה הפרויקט

- `app.py` — שרת FastAPI: טעינת המודל, endpoints לחיזוי ולניתוח ביצועים, הגשת קבצים סטטיים, לוגים.
- `loan_model.pkl` — ה-pipeline המאומן (StandardScaler + SVC).
- `loan_data_v2.csv` — דאטהסט האימון.
- `Loan_Forecasting_Project.ipynb` — המחברת המקורית שממנה נגזר המודל.
- `static/` — ממשק המשתמש: `index.html`, `app.js` (טופס + i18n), `analytics.js` (לוח הביצועים), `styles.css` — ללא תלות בספריות frontend חיצוניות.
- `tests/` — בדיקות `pytest` ל-API.

## הרצה מקומית

```bash
pip install -r requirements.txt
python app.py
```

השרת עולה בכתובת `http://localhost:8000`.

## API עיקרי

| Method | Path | תיאור |
| --- | --- | --- |
| GET | `/api/health` | בדיקת תקינות |
| GET | `/api/model-info` | מידע על המודל והגורמים המשפיעים |
| POST | `/api/predict` | חיזוי אישור הלוואה עבור בקשה בודדת |
| GET | `/api/model-analytics` | מטריקות ביצועים מלאות (מטריצת בלבול, דוח סיווג, גבול החלטה, דגימות דאטה) |
| POST | `/api/retrain-model` | אימון מחדש של ה-Pipeline מ-`loan_data_v2.csv` ושמירתו |
